# ansible-life-hacks

### ansible и программирование
Говорят что одна из best practice для ansible - "Не программируй на ansible".

Спустя 5 лет работы с инструментом, у меня возникло двоякое отношение к этой рекомендации.

С одной стороны, включение логики внутрь тасков, ухудшает читаемость, \
с другой - без логики автоматизировать многие вещи становится сложно.

Таким обазом мы встаем перед выбором:
1. Пишем простые читаемые роли, и получаем недоконфигурированные сервисы
2. Учим python и пишем свои модули
3. Используем доступный функционал ansible + jinja2 и пишем более внятные README.md

На данный момент мне больше нравится третий путь.
